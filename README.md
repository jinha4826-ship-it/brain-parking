# 🅿️ 생각주차장 · 뇌 비우기 주차장

머릿속에 할 일·걱정·잡생각이 한꺼번에 떠올라 아무것도 못 하는 **과부하 마비(선택 마비)**를 10초 만에 풀어주는 웹앱입니다.

**라이브**: https://jinha4826-ship-it.github.io/brain-parking/

## 무엇을 하나요
1. **던져넣기** — 큰 입력창에 Enter로 생각 조각을 계속 던져놓습니다. 상단의 🫧 과부하 게이지가 쌓일수록 붉어집니다.
2. **머릿속 정리하기** — 로컬 키워드 분류로 세 구역에 나눕니다.
   - 🔥 **지금 딱 1개** — 최대 1개. 이미 차 있으면 "지금은 1개만! 나머지는 주차장에 맡겨요" 안내. [시작콩](https://jinha4826-ship-it.github.io/sijakkong/)으로 5분 시작 연결.
   - 🅿️ **나중에 주차** — 잊어버릴까 불안한 일을 안전하게 맡겨두고, 체크로 완료 처리.
   - 🍃 **흘려보낼 걱정** — 통제할 수 없는 것들을 부드럽게 사라지는 애니메이션과 함께 내려놓기.
3. **내 비움 기록** — 비운 생각 수, 흘려보낸 걱정, 완료한 일, 막히는 유형(할 일 과부하 vs 걱정 과부하), 최근 7일 기록.

## 개인정보
모든 기록은 서버로 보내지 않고 브라우저 `localStorage`에만 저장됩니다. 기록 전체 지우기로 언제든 삭제할 수 있습니다.

## 구성
단일 `index.html` (외부 라이브러리·API 없음). iPhone Safari 기준 모바일 퍼스트.
